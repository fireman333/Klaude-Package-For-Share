# writing-style-builder — 建立並使用你的個人寫作風格檔

這是一個**空白模板型** skill：它不帶任何人的風格，而是教 Claude 從**你自己的**文章樣本歸納出風格，存成 `profile.md`，之後照著寫。

## 使用方式（先判斷是哪一種意圖）

| 你說的話 | 走哪一段 |
|---|---|
| 「分析我的風格」「建立風格檔」＋貼文章／給檔案路徑 | A. 建檔 |
| 「用我的風格寫 X」「照我的語氣寫」 | B. 使用 |
| 「更新風格檔」「再加幾篇樣本」 | A 的 Step 1–4 重跑（沿用既有 profile，只做差異修訂） |

工作資料夾預設 `./my-writing-style/`（你可以指定別處）：

```
my-writing-style/
├── profile.md          # 風格檔（本 skill 的產出）
├── samples-index.md    # 樣本清單（標題／日期／模式／字數／備註，不重複貼全文）
└── samples/            # （選用）你的原稿副本，只留本機
```

> 隱私：樣本是你的個人文字，留在本機。若樣本含他人姓名、病人資訊、機構內部資料，先自行遮蔽再給 Claude；病歷類請先用 `phi-deid`（klaude-med）去識別化。風格檔本身**不要**收錄樣本原句，只記規律。

## A. 建檔流程

### Step 1：收樣本與選模式
- 收 **5–15 篇**同一種用途的文章（少於 5 篇規律不穩；超過 15 篇邊際效益低）。每篇 300 字以上較好。
- 問清楚兩件事（一次問完）：
  1. 模式：**學術／臨床／email**（讀者是老師、同儕、主管、審稿人）或 **大眾科普／部落格**（讀者是非專業的一般人）。兩種語氣差很多，**分開各建一份 profile**，不要混在一起平均（例如 `profile-academic.md`、`profile-public.md`）。
  2. 你想保留的、以及想改掉的習慣（例如「我太常用被動語態，想改」）。想改的寫進 profile 的「刻意修正」欄，不當作風格。
- 用 `${CLAUDE_SKILL_DIR}/templates/samples-index.template.md` 建 `samples-index.md`：每篇一行（檔名、日期、模式、字數、備註）。

### Step 2：逐項分析（維度清單）
對每一篇樣本都過一遍下列維度，**記錄頻率與傾向，不只記「有／沒有」**；最後跨篇彙整，只有在**多數樣本重複出現**的才算風格，單篇才有的是巧合。

**A. 語氣與立場**
- [ ] 人稱（我／我們／無人稱）與對讀者的距離（平等、請教、教學）
- [ ] 態度光譜：謙遜 ↔ 自信；溫暖 ↔ 冷靜；批判是否緩和
- [ ] 是否說教、是否常用「應該」「必須」
- [ ] 情緒表達的量（克制／外放）

**B. 句式**
- [ ] 平均句長（短句為主／長複句為主）；一段幾句
- [ ] 慣用句型（遞進、對比轉折、括號補充、設問反問、列舉）
- [ ] 標點習慣（全形／半形、破折號、刪節號、驚嘆號頻率）
- [ ] 常見連接詞與轉折詞

**C. 用詞**
- [ ] 口語詞 ↔ 書面詞比例；台灣慣用語 vs 其他地區用語
- [ ] 中英夾雜規則（哪類詞保留英文、首次出現是否附中譯）
- [ ] 四字詞／成語密度；比喻與類比的偏好
- [ ] **禁用詞／避免的詞**（樣本中從不出現、或你明說不喜歡的）
- [ ] 口頭禪與招牌詞（只記「類型」，不抄原句）

**D. 結構**
- [ ] 開場方式（個人經驗／問題／場景／總論／數字）
- [ ] 段落組織（先總後分、層次遞進、對照）
- [ ] 收尾方式（正面收束、留問題、行動呼籲、不收尾）
- [ ] 標題與小標風格；是否用條列、表格、粗體

**E. 內容處理**
- [ ] 舉例來源（個人經驗、病例、新聞、研究）
- [ ] 引用與數據的呈現方式（括號引用、腳註、直接敘述）
- [ ] 不確定性與限制的講法

**F. 版面與長度**
- [ ] 常見字數區間、段落長度、emoji／符號使用

### Step 3：寫入 profile.md
複製 `${CLAUDE_SKILL_DIR}/templates/profile.template.md` 到 `./my-writing-style/profile.md`，把每一欄填成**可執行的規則**：
- 每條規則寫成「做什麼／不做什麼」+ 一個**自己造的**示意短句（不要貼樣本原句，避免洩漏私人內容）。
- 分成 **Hard rules**（幾乎每篇都成立，違反就不像你）與 **Soft tendencies**（多數成立，可視情境彈性）。
- 必填「反例清單」：Claude 容易寫出、但你不會寫的句子類型（例如過度客套、AI 腔的排比、空泛結語）。

### Step 4：驗證 profile（盲測）
1. 取一篇你的樣本，只給 Claude 它的**題目與大綱**，請它依 profile 寫一版。
2. 派一個獨立 sub-agent（不讀原文，只讀 profile）對照原樣本與新稿，逐維度列出落差。
3. 落差大的維度回頭修 profile；最多兩輪。
4. 讓你本人看過並簽收（「像我／不像我」的最終判斷只有你能下）。

回報：profile 路徑、各維度信心（高／中／低）、哪幾條規則證據偏少（建議多補樣本）。

## B. 使用流程（「用我的風格寫 X」）

1. 讀 `./my-writing-style/profile.md`（沒有就走 A；有多份就問用哪個模式）。
2. 確認任務：主題、讀者、長度、平台、是否有必須包含的事實／引用。
3. **先出大綱**（3–7 點），再寫初稿。內容的事實準確性優先於風格；風格不能拿來掩蓋不確定的事實。
4. 自檢 rubric（逐條打勾再交稿）：
   - Hard rules 全部符合？
   - 有沒有踩到「禁用詞」與「反例清單」？
   - 開場、收尾是否符合該模式的慣例？
   - 長度、標點、中英夾雜規則是否符合？
5. 交稿時附一小段「風格自評」：哪些規則做到、哪幾處不確定，讓使用者快速微調。使用者的修改若形成新規律，詢問是否寫回 profile。

### 兩種模式的差異提示

| 面向 | 學術／臨床／email | 大眾科普／部落格 |
|---|---|---|
| 讀者假設 | 有專業背景、時間少 | 無背景、需被吸引 |
| 開場 | 直接點明目的／背景 | hook：場景、問題、反直覺事實 |
| 句子 | 精確、可較長 | 短句、口語、一句一重點 |
| 術語 | 直接用，首次附全稱 | 用比喻解釋，術語少而精 |
| 結論 | 保守措辭、標明限制 | 正面但誠實、不誇大 |
| 禁忌 | 口語化、情緒化 | 艱澀、說教、恐嚇式標題 |

衛教／科普內容涉及醫療主張時：不要因為「好讀」而把未達統計顯著的結果寫成有效；數字與結論以來源為準。

## 重要提醒
- 風格檔描述的是**規律**，不是樣本的摘錄；不要把樣本原句寫進 profile 或對外分享。
- 分享給別人的是這個 skill 模板，不是你的 `my-writing-style/` 資料夾（那是你的私人資料）。
- 若你的署名、身分或資格有法規限制（例如醫療專業稱謂），請自行在 profile 的「署名與身分」欄寫明，Claude 會照辦。
