# Nature — Writing & Caption Voice

## Tone
- Narrative, broad-impact framing. Lead with the **biological / mechanistic insight**, not the technique.
- Active voice preferred. "We show that …" is welcome (Nature is one of the few BMJ-style allowed-first-person venues).
- Avoid hedging stacks ("might possibly suggest"). One hedge per sentence max.

## Abstract
- **Unstructured**, ~150 words.
- Opening sentence = field-level context (one breath, no jargon density).
- Second sentence = the gap.
- Body = key findings with effect sizes.
- Closing sentence = implication / generalisation.

## Figure caption template
```
Fig. {n} | {Bold short title}. {One-sentence summary of the experiment / dataset}. a, {panel a description}. b, {panel b}. ... Error bars indicate {sd | sem | 95% CI, n = X}. {Statistical test}, {p-value notation}.
```
- Bold the title (everything before the first period).
- Lower-case panel labels (`a`, `b`, `c`).
- Inline statistical notation (e.g. `*P < 0.05, **P < 0.01`).

## Cover letter
- 1 page max.
- Open with one sentence on broad significance ("Why every Nature reader should care").
- One paragraph on the finding.
- One paragraph on novelty vs prior literature.
- Close with suggested reviewers (3 names + reason).
