# Title + Abstract (+ Key-message box, Keywords) — rules distilled from 14-paper corpus

Source tags: A1–A4 writing guides; B1 NEJM RCT; B2 BMJ pragmatic RCT (NS primary); B3 BMJ cohort; B4 BMJ population observational; C1 dose-response MA; C2 network MA; C3 pairwise MA of RCTs; D1 SR+MA; D2 SR without MA; D3 umbrella review. Items tagged [ext] come from standard reporting guidance (CONSORT/PRISMA abstract extensions), not from the corpus.

## 1. Job of this section
The title and abstract are read by far more people than any other part [A1], and the abstract is often the only part read; editors and reviewers form a first impression from it [A4]. Write them LAST, after results and discussion are final [A4]. The abstract must stand alone (what was asked, how, what was found, what it means) and must never add information absent from the main text [A4,B2]. Title = one findable, accurate scope statement; abstract = compressed, number-bearing story.

## 2. Move structure by article type

### 2a. Title patterns (slotted; pick by design)
| Type | Pattern | Tags |
|---|---|---|
| RCT (NEJM) | `[Intervention] for [Condition] and [Comorbidity]` — design NOT in title | B1 |
| RCT (BMJ) | `[Trial acronym]: [concept] following [condition]: [pragmatic/multicentre], randomised controlled trial` — design label after colon; no result or comparator in title | B2 |
| Cohort | `[Exposure] and risk of [outcome]: [cohort name] prospective cohort study` — exposure first, outcome second, design last | B3 |
| Population observational | `[Exposure/Programme] and [outcome 1] and [outcome 2] by [stratifier] in [setting]: [design descriptor]` | B4 |
| Pairwise MA | `Effect of [exposure] on [outcome family A] and [B] in [population]: systematic review and meta-analysis of randomised controlled trials` | C3 |
| Dose-response MA | `[Exposure] intake and risk of [outcome list]: systematic review and dose-response meta-analysis of prospective cohort studies` | C1 |
| Network MA | `Comparative [efficacy/effects] of [drug class] for [phase of care] of [condition] in [population]: systematic review and network meta-analysis` | C2 |
| SR with MA | `[Exposure] and [outcome class]: systematic review and meta-analysis` | D1 |
| SR without MA | `The impact of [exposure category] on [outcome A] and [outcome B]: a systematic review` | D2 |
| Umbrella review | `[Exposure] and [outcome domain]: umbrella review of [meta-analyses of observational studies]` | D3 |

Title rules: 11–27 words [B1,B4,C1,C3]; exposure → outcome → population/setting; design label after a colon for BMJ-style journals, mandatory for reviews/observational (STROBE 1a, PRISMA 2020 item 1) [B3,C1–C3,D1–D3]; no "novel", no effect-size adjectives, no result in the title [D1,D3]; use "association" language in titles of observational studies — do NOT copy B4's use of "Effect of" for an observational design (the corpus shows it, but it conflicts with the causal-language ladder in section 7). State one central contribution [A1].

### 2b. Abstract moves
| Type | Heading set (journal-dependent) | Moves in order |
|---|---|---|
| RCT, NEJM style [B1] | BACKGROUND / METHODS / RESULTS / CONCLUSIONS (+ funding and NCT number in parentheses at end) | context + hedged rationale → design, blinding, randomisation, population, comparator, duration, primary + key secondaries → baseline, then effect per trial/outcome, then safety → declarative conclusion |
| RCT, BMJ style [B2] | Objective / Design / Setting and participants / Interventions / Main outcome measures / Results / Conclusions / Trial registration | aim → design → setting, eligibility → arms with n and analysis principle → primary outcome + timepoint → recruitment, completeness, primary estimate with CI, NS statement, complications → "not superior to" conclusion → registry ID |
| Observational cohort [B3] | Objective / Design / Setting and participants / Main outcome measures / Results / Conclusions / Study registration | aim → design + follow-up → cohort, N, age, follow-up, exposure measurement → model + confounder handling → cases, effect per increment, null exposures in same block → hedged interpretation + replication need |
| Population observational [B4] | Objectives / Design / Setting / Participants / Main outcome measures / Results / Conclusions | aim (replicate + extend) → design → setting → participants with counts → outcomes → relative and absolute reductions, then stratified (equity) result → association-worded conclusion |
| Pairwise MA [C3] | Objective / Design / Data sources / Eligibility criteria / Outcome and measures / Data extraction and synthesis / Results / Conclusions / Study registration | purpose (+ guideline context) → design + databases + end date → eligibility → primary then secondary outcomes → extraction/pooling → pooled estimate, CI, I², certainty → hedged conclusion + population limit → registration |
| Dose-response MA [C1] | Objective / Design / Data sources / Study selection / Data synthesis / Results / Conclusions | adds: model for dose-response; results give highest-vs-lowest pooled estimate, then per-increment slope as last, most quotable number; null outcome sits beside positive ones |
| Network MA [C2] | Objective / Design / Data sources / Eligibility criteria / Methods / Results / Conclusions (+ registration) | adds: duplicate/independent screening, model type, certainty tool (CINeMA/GRADE); results = vs-placebo range, head-to-head ranking, certainty range, sensitivity-analysis sentence; conclusion = verdict, caveat, future-study call |
| SR with MA [D1] | Objective / Design / Data sources / Review methods / Results / Conclusions / Review registration | question with adjustment qualifier → sources + dates → eligibility + strata → N studies + denominator + risk-of-bias n (%) → subgroup estimates → null outcomes in ONE sentence → heterogeneity drivers → conditional conclusion + research recommendation |
| SR without MA [D2] | Aim / Design / Data sources / Review methods / Results / Conclusions | name reporting guideline (PRISMA) AND synthesis guideline (SWiM) + appraisal tool; results = counts, direction of consistent finding, then what is inconclusive; no effect sizes |
| Umbrella review [D3] | Objective / Design / Data sources / Eligibility criteria / Results / Conclusions / Registration | define evidence-grading schemes (credibility classes, GRADE) in eligibility; results = count of pooled analyses (dose-response vs not, participants), % with direct association, class I outcomes with effect + GRADE in same parenthesis, class II, remainder as count, GRADE tally |

Universal abstract order: background/gap → question → methods → results → answer → importance [A4]; "broad–narrow–broad" shape for unstructured abstracts, with "Here we" marking the content move [A1]. Never lead with results before the reader knows the question [A1].

### 2c. BMJ "What is already known / What this study adds" boxes [B2,B4,D1,D3]
- Two headed lists, 2–3 bullets each, one sentence per bullet (≤30 words), ~40–150 words total, no CIs, no citations.
- Known: (1) state of practice or trend, (2) range of options or outcome gap, (3) evidence gap ("no previous trial / comprehensive review") [B2,D1,D3].
- Adds: (1) size/scope of the study, (2) main finding in plain words with NS phrased as "did not significantly improve", (3) what it lets clinicians/policy-makers do ("evidence-informed discussions", "support research/policy") [B2,D3]. Align bullet wording with abstract outcome names.

### 2d. Keywords [A4]
3–10 terms from a controlled vocabulary (MeSH); differ from title words (variants allowed); avoid very general terms; test candidates by searching and checking retrieval. NEJM/BMJ often omit keywords — follow the target journal's author guide.

## 4. Template bank (slotted; adapt, do not copy)
**Objective / aim**
1. To assess the effect of [intervention] compared with [comparator] on [outcome] in [population].
2. To examine the association between [exposure A], [exposure B], and risk of [outcome] [B3,C1].
3. To investigate the association between [exposure] and [outcomes] after adjustment for [minimum confounders] [D1].
4. To evaluate the existing meta-analytic evidence of associations between [exposure] and [outcome domain] [D3].
5. To compare all licensed [drug classes] for [phase] of [condition] in [population] [C2].
**Design / setting / participants**
6. [Pragmatic/double-blind], [N]-arm, [multicentre] randomised controlled trial.
7. Prospective cohort study followed for a median of [N] years.
8. [N] adults ([mean] [SD] age) from the [cohort name] cohort, enrolled [years], with [exposure] assessed by [method].
9. Women aged [range] resident in [setting] between [dates], including [n1] with [outcome 1] and [n2] with [outcome 2] [B4].
**Interventions / outcomes**
10. [Arm A] (n=[N]) was compared with [arm B] (n=[N]); analysis followed intention-to-treat principles.
11. The primary outcome was [measure] at [timepoint]; secondary outcomes included [list].
**Review methods**
12. [Databases] were searched from inception to [date]; [screening, extraction, bias assessment] were done independently and in duplicate.
13. Random effects models pooled [effect measure] with 95% confidence intervals; certainty was graded with [GRADE/CINeMA].
14. Reporting followed [PRISMA 2020]; synthesis followed [SWiM]; quality was appraised with [tool] [D2].
**Results**
15. Of [N] participants randomised, [n] ([%]) completed the primary outcome.
16. [Outcome] was [value] with [intervention] and [value] with [control] (difference [x], 95% CI [a] to [b]).
17. There was no statistically significant difference between groups for [primary outcome] ([estimate], 95% CI [a] to [b]).
18. [Exposure] was positively associated with [outcome] (HR [x] per [increment], 95% CI [a] to [b]); [exposure 2] was not associated with [outcome] (P>[thr]).
19. [N] studies ([total denominator] [units]) were included; [n] ([%]) had low or medium risk of bias.
20. The pooled [measure] for highest versus lowest [exposure] category was [x] (95% CI [a] to [b]; I²=[y]%).
21. [k] ([p]%) of [m] pooled analyses showed a direct association; [class I] evidence supported [outcome A] ([measure] [x], [a] to [b]; GRADE [level]).
22. Incidence was [x]% (95% CI [a]% to [b]%) lower in the [exposed cohort] than in the reference cohort, and [direction] across all [k] [stratifier] groups.
23. No clear evidence of differences was found for [outcome list] after adjustment.
24. Confidence in the evidence ranged from [grade] to [grade] [C2].
**Conclusions**
25. [Intervention] reduced [outcome 1] and improved [outcome 2] among [population] (RCT with significant primary result only) [B1].
26. [Intervention] was not superior to [comparator] for [outcome] at [timepoint] [B2].
27. [Exposure] was associated with [higher/lower] risk of [outcome]; findings need replication in [design].
28. The evidence is [low/very low certainty] and limited to [population]; future [design] should [specific action].
**Registration / funding**
29. Trial registration [registry] [ID]. / Review registration PROSPERO [ID].
**Box**
30. No previous [trial/comprehensive review] was available to inform [decision].

## 5. Tense / voice / person
| Element | Tense | Voice / person |
|---|---|---|
| Objective / Aim | present infinitive ("To assess") or present | no pronoun |
| Design, Setting, Methods | past (or noun phrases) | passive or "we" (NEJM) [B1] |
| Results | past | active/passive; no interpretation |
| Conclusions | past for the finding ("was associated with"), present + modal for implication | impersonal (no "we"); bare active verbs only for a randomised contrast [B1] |
| Box bullets | present perfect for known; past for findings | impersonal |
| Title | noun phrase | no verbs ideally |

## 6. Hedging inside Conclusions: claim-strength ladder
Strongest → weakest; use the strongest the design licenses and no higher.
1. "[Drug] reduced / improved [outcome]" — only a randomised comparison with a statistically significant, prespecified primary outcome [B1].
2. "[Exposure] was associated with…" — default for all observational designs and meta-analyses of them [B3,B4,C1,D1,D3].
3. "…might represent a modifiable risk factor" / "could be associated with" — interpretive hedge for observational signals; add replication need [B3,C1].
4. "Results suggest…" / "support" — pooled RCT evidence of moderate or lower certainty [C3].
5. "…was not superior to [comparator]" — superiority trial without a significant difference [B2].
6. "No statistically significant difference" / "did not differ significantly" — any NS result; ALWAYS pair with point estimate + CI. Never "no difference", "equally effective", "equivalent" unless a non-inferiority/equivalence margin was prespecified and the CI lies inside it.
7. "Inconclusive / evidence remains limited" — SR without MA, heterogeneous or low-certainty evidence [D2].
Rules: observational design → no causal verbs (reduces, prevents, causes, effect of). A CI crossing 1 is never "reduced by X%". Report null findings in Results and Conclusions, not omitted [A4,B3,D1]. "Significant" only with statistical meaning and a P/CI. Tier evidence strength by named grade (GRADE, credibility class), not by adjectives [D3]. Do not claim "first" or "novel".

## 7. Numbers & statistics formatting
- Effect = estimate + 95% CI in "a to b" (BMJ) or "[a to b]" (NEJM); exact P (P<0.001 floor); never P alone — attach estimate and N [A4,B1].
- Give absolute AND relative where possible (counts + %, difference in units, prevented cases with CI) [B4]. Denominator with every percentage: n/N (%) [B2,D1].
- Ranges across comparisons as "from X to Y" instead of tables [C2].
- Effect per increment written inside parentheses with unit [B3]. I² inline with pooled estimate [C1,C3]. OR/HR to 2 decimals; baseline means 1 decimal; true minus sign (−) [B1].
- Certainty/grade in the same parenthesis as the estimate [D3]. Small counts in abstracts may be words (D2) but prefer numerals for consistency with the journal.
- No figures, tables, or citations in the abstract; if a prior work must be named, give a full reference [A4].
- Primary outcome name identical in Objective, Methods and Results [C2].

## 8. Reporting-guideline checklist
- **CONSORT 2010 for Abstracts** (2025 version renumbered; map separately): 1a design in title (BMJ; NEJM places in abstract) [B1,B2]; 1b structured abstract: trial design, participants/eligibility, interventions, objective, primary outcome, randomisation method, blinding, N randomised and analysed per arm, primary result with effect size + CI, harms, conclusions, trial registration number, funding [B1,B2] [ext].
- **STROBE 1a/1b**: study design in title or abstract with a commonly used term; informative balanced summary [B3,B4].
- **PRISMA 2020 for Abstracts** [ext]: title identifies as SR; objectives; eligibility criteria; information sources with last-search date; risk-of-bias method; synthesis method; included studies (number, characteristics); synthesis results with effect + CI + direction of effect; limitations of evidence (risk of bias, inconsistency, imprecision); interpretation (general interpretation and implications); funding; registration name and number. PRISMA-NMA adds network geometry/ranking and certainty; MOOSE for observational MAs; SWiM named for narrative synthesis [D2].
- **GRADE / credibility classes**: state certainty for the primary finding in abstract [C3,D3].
- Registration ID and (if required) funding line present [A4,B1,D1].

## 9. Do / Don't
- DO open the Objective with an infinitive and name exposure, comparator, outcome, population. | DON'T open with background sentences in BMJ-style abstracts.
- DO report the primary result with estimate + CI + (P). | DON'T report a P value alone.
- DO include null/secondary-negative findings in one clause. | DON'T drop them or bury in discussion.
- DO match abstract numbers to main text exactly. | DON'T add new analyses in the abstract.
- DO use "associated with" for observational data. | DON'T use "effect of / reduces / causes".
- DO state registration and reporting guideline. | DON'T cite references or describe standard lab methods.
- DO give design in title for reviews and observational studies. | DON'T put result, "novel", or adjectives in the title.
- DO choose 3–10 MeSH-derived keywords not duplicating the title. | DON'T use broad terms like "treatment".

## 10. LLM-draft failure modes → fix
| Tell | Why it reads as AI / is wrong | Rewrite pattern |
|---|---|---|
| "…is a pivotal/pressing challenge in the evolving landscape of…" opening | Generic filler; no data | Drop; start with Objective infinitive or a quantified burden clause |
| Conclusion restates results ("In summary, X was 12% and Y 8%") | Redundant; abstracts conclude, not recap [A4] | One sentence: answer + hedged implication + specific next study |
| "novel", "first study to", "comprehensive", "robust" | Unverifiable priority claims [C1] | Delete; state the gap in the box ("no previous trial…") |
| "No difference" / "equally effective" for NS result | Absence of evidence ≠ equivalence | "No statistically significant difference (diff [x], 95% CI [a] to [b])"; "not superior to" |
| "Reduces risk by 16%" with CI crossing 1 | Misreads a NS HR | Report HR + CI, label NS, drop the percentage |
| Causal verbs ("leads to", "drives") for cohort data | Design cannot support | "was associated with"; "might represent" |
| Triplet adjective lists ("significant, robust, meaningful") | Pattern-filler | Replace with numbers and named certainty grade |
| Missing denominators or only P values | Uninterpretable [A4] | n/N (%) and estimate + CI |
| Abstract introduces claims absent from the paper | Inconsistent with text | Draft from key sentences of each section, then trim [A4] |
| Title as full sentence/result or ending with "A Systematic Review and Meta-Analysis of the Evidence" fluff | Wrong register | `[Exposure] and [outcome]: systematic review and meta-analysis` |
| Box restates abstract with CIs and hype | Box is plain-language, no stats | 2–3 short bullets: known / gap / what adds |
| "Further research is needed" | Vague call [A4] | Name design + population of the next study |

## 11. Mini worked example (fictional)
**Before (LLM-style):**
"Title: A Novel Comprehensive Investigation of Drug X for Improving Outcomes in Heart Failure. Abstract: Heart failure is a pivotal public-health challenge in the modern healthcare landscape. We conducted a robust trial. Drug X significantly reduced hospitalisations by 14% and was equally effective as standard care for mortality. Our novel findings underscore that Drug X is a game-changer and further research is needed."

**After (journal-style):**
"Title: Drug X versus placebo for heart failure with preserved ejection fraction: randomised controlled trial.
Objective: To assess whether drug X reduces hospital admission in adults with heart failure with preserved ejection fraction.
Design: Double-blind, placebo-controlled randomised trial.
Setting and participants: 38 hospitals, 1210 adults aged 60 or older with NYHA class II–III symptoms.
Interventions: Drug X 10 mg daily (n=606) or placebo (n=604) for 12 months; intention-to-treat analysis.
Main outcome measures: First heart-failure admission.
Results: Admission occurred in 124/606 (20.5%) with drug X and 151/604 (25.0%) with placebo (hazard ratio 0.80, 95% CI 0.63 to 1.01; P=0.06). There was no statistically significant difference in all-cause mortality (31 v 36 deaths; HR 0.86, 95% CI 0.53 to 1.39).
Conclusions: Drug X did not significantly reduce first heart-failure admission compared with placebo; the CI was compatible with a 37% reduction and a 1% increase.
Trial registration: ClinicalTrials.gov NCTxxxxxxxx."

## Source conflicts resolved
- B4 puts "Effect of" in an observational title; this skill mandates association wording (claim-strength section) — flagged, not copied.
- Heading sets vary by journal (NEJM 4-heading vs BMJ 7–9-heading); the heading set follows the target journal, the moves stay constant.
