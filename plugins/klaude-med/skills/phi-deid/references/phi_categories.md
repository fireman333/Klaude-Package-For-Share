# PHI 類別清單 + 台灣法規依據

## 為何需要去識別化

把病人資料送進雲端 LLM（包含 Claude Code 本身）等同於「對外揭露」。根據台灣 個人資料保護法（個資法）§2 與 HIPAA 的類比框架，「個人資料」涵蓋可直接或間接識別個人的所有資訊。**即使去除姓名與身分證字號**，若保留足夠的 quasi-identifier（出生日期 + 性別 + 郵遞區號 + 罕見職業），仍可能重新識別（k-anonymity literature 的基本發現）。

> **匿名（anonymization）** vs **去識別化（de-identification）** 的差別：
> - 匿名 = 無法還原、永久切斷與真實個人的連結。
> - 去識別化 = 透過 mapping 仍可還原，但 mapping 本身是受控的。
>
> `phi-deid` 這個 skill 做的是 **去識別化**（reversible），不是匿名。因為使用情境需要把草稿還原貼回 HIS。

## 偵測目標（HIPAA 18 項 + 台灣特有）

### A. 直接識別符（必須完全移除或替換）

| 類別 | 範例 | Pseudonym | 偵測層 |
|---|---|---|---|
| **病人姓名** | 王小明 | `[PATIENT_NN]` | Lexicon 姓氏 + 職稱語境 + CKIP PERSON |
| **家屬姓名** | 王陳美麗太太、長子王大華 | `[FAMILY_NN]` | 關係語境（太太 / 兒子 / 之父 / 之母…）|
| **醫護人員姓名** | 張國榮教授、R2 黃志強、李美麗 NS | `[DOCTOR_NN]` / `[NURSE_NN]` | 職稱（主治醫師 / R1-5 / CR / PGY / Dr. / Attending / 護理師 / 專師）|
| **身分證字號** | A123456789 | `[NATIONALID_NN]` | regex `^[A-Z][12]\d{8}$` |
| **外籍統一證號** | AA12345678 / AB12345678 | `[UINUMBER_NN]` | regex `^[A-Z](?:[89]\|[A-D])\d{8}$`（新舊格式）|
| **健保卡號** | 000098765432 | `[NHICARD_NN]` | 12 位數字 + 語境 |
| **病歷號 / 住院號 / 病理號 / 影像號 / 檢驗單號** | A1234567 / ADM20240315001 / S-24-01234 | `[MRN_NN]` / `[ADM_NN]` / `[PATH_NN]` / `[ACCESSION_NN]` / `[LAB_NN]` | 語境 regex |
| **床號** | 12A-03 | `[BED_NN]` | 語境 regex（需 "床號"/"Bed" 前綴）|
| **手機** | 0912-345-678 | `[PHONE_NN]` | regex `09\d{2}[-\s]?\d{3}[-\s]?\d{3}` |
| **市話** | 02-1234-5678 | `[PHONE_NN]` | regex `0[2-8][-\s]?\d{3,4}[-\s]?\d{4}` |
| **Email** | patient@xxx.com | `[EMAIL_NN]` | regex |
| **LINE ID** | `LINE: wangxm1952` | `[LINEID_NN]` | regex `LINE(?:\sID)?:` |
| **車牌** | ABC-1234 | `[PLATETW_NN]` | regex（外傷 note 偶見）|
| **地址（含路街巷弄號樓室）** | 臺北市大安區仁愛路四段123號5樓 | `[ADDRESS_NN]` | 22 縣市 anchor + 區/鄉/鎮/路/街/巷/弄/號/段/樓 |

### B. 日期（Quasi-identifier —— shift 不刪除）

| 類別 | 處理方式 | 說明 |
|---|---|---|
| 出生日期、入院日、手術日、progress note 日期 | 隨 session offset 隨機 shift ±365 天 | 保留日期格式（ISO / 民國 / 年月日）與相對關係（「手術後第3天」數字不變） |
| 民國年份 | 同上（民國113年→民國114年等） | 自動處理西元與 ROC 年轉換 |
| HH:MM 時間 | **保留不動** | 時間本身不具識別性；保留臨床時序語意 |
| `POD#3` / `HD4` / `住院第5天` / `q8h` | **保留不動** | 相對時間 token 不是日期，保護不讓 regex 誤 shift |

### C. Quasi-identifier（保留 / 人工判斷）

這些項目**不自動刪除**，但若組合起來可能重新識別，需使用者人工判斷：

| 類別 | 說明 |
|---|---|
| 科別 | 臨床必要，保留不動（「感染科」「血液腫瘤科」等）|
| 年齡 | 保留（「72 歲男性」）|
| 性別 | 保留 |
| 職業 | 僅當為罕見職業（離島漁民、特定工廠員工等）才 flag |
| 原住民族別、宗教 | lexicon 偵測到時 flag，不自動替換 |
| 罕見疾病診斷 | 保留（臨床必要），但使用者應意識到組合風險 |

### D. 機構名稱（半識別符）

| 類別 | 處理 |
|---|---|
| 某醫學中心、林口長庚、馬偕、三總… | 替換成 `[HOSPITAL_NN]` |
| 一般「醫院」「診所」「衛生所」 | 保留（太泛用）|

## 為什麼不刪除 quasi-identifier

LLM 起稿需要臨床情境才能寫出合理的 note。完全刪除「72 歲男性 + 感染科 + 糖尿病史」會讓草稿變成無意義的模板。取捨點：

- **刪除直接識別符**（姓名、ID、地址、電話）—— 移除就失去個人關聯。
- **保留 quasi-identifier 的臨床部分**（年齡、性別、科別、病史）—— 這些是臨床邏輯必需。
- **Shift 日期** —— 保留相對時序但打破絕對日期的 linkage。

使用者要意識到：**組合多個 quasi-identifier 仍可能重新識別**（例如「某醫學中心胸腔科 40 歲女性 + ALK 陽性肺癌 + 2024-03-15 入院」在小範圍內可能唯一）。若該 note 的內容足以組成這種組合，使用者需自行判斷是否應把更多細節也去識別化。

## 台灣特有 PHI 格式

### 身分證字號（National ID）

- 格式：`[A-Z][12]\d{8}`（10 碼）
- 第 1 碼：英文大寫，代表戶籍縣市
- 第 2 碼：1（男）/ 2（女）
- 第 3-10 碼：流水號 + 檢核碼

### 外籍統一證號（UI Number）

- 舊格式：`[A-Z][A-D]\d{8}`（2020 前）
- 新格式：`[A-Z][89]\d{8}`（2020 起）
- 第 2 碼 8/9 代表男/女（新制）；A/B/C/D 代表居留類別（舊制）

### 民國年份

- 台灣公文、部分病歷系統仍用民國紀年。
- 換算：民國年 + 1911 = 西元年。例：民國 113 年 = 2024 年。
- date_shift 同時支援：
  - `民國113年3月15日`
  - `113年3月15日`（無民國前綴）
  - `民國113-3-15` / `民國113/3/15`

### 健保卡號

- 12 位數字。格式本身不具強識別性（無校驗碼），因此需要語境 `健保卡號:` 才偵測，避免誤判其他 12 位數序列。

### 病歷號（MRN）

- 各醫院格式不一，常見：
  - 某醫學中心：`A1234567`（英文 + 7 位數字）
  - 榮總：`24000123`（純數字）
  - 長庚：`LK12345678`（院區縮寫 + 數字）
- 因此不能靠格式本身，必須有「病歷號:」「Chart No.」「MRN」「HN」等語境前綴。
