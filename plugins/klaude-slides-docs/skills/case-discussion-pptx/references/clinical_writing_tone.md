# 中文臨床報告語氣指南（簡版）

適用：中文臨床報告、case discussion 書面內容、臨床決策建議。不適用：日常對話、英文投影片本文。

原則：報告是 evidence-based 的客觀陳述，不是臨床命令；所有建議以「建議 / 可考慮 / 宜評估」呈現，最終決策留給主治醫師。

| 避免 | 改用 |
|---|---|
| 立即停藥 / 馬上停 | 建議停用 / 可考慮停用 |
| 必須 / 一定要 / 絕對 | 建議 / 宜 / 通常 |
| 強烈建議 | 建議 |
| 完全避免 / 永遠不要 | 宜避免 / 通常不建議 |
| 無任何 indication | 較難找到合理 indication |
| 拿不到 benefit | 未顯示 benefit |
| double hit / red flag / 神藥 / game-changer | 風險疊加 / 警訊 / 重要進展 |

句式：少用否定句堆疊與反問句；避免主觀價值判斷（改成「風險效益比偏負面」）；條件式陳述（「若 LVEF preserved 則…」）可以。

統計措辭：未達統計顯著 ≠ 沒有差異。寫「無統計顯著差異 / 未達顯著」，不要寫「沒差」「無效」；HR 的 95% CI 跨 1 時不要寫成「降低 X%」。

套用順序：寫初稿就用保守措辭 → 交付前 grep 上表左欄詞 → 命中即改。
